# LED シューティングゲーム

micro:bit の 5×5 LED 画面で遊べる、シンプルな縦シューティングゲームです。

## ゲーム概要

- プレイヤーは画面最下段に表示されます
- 上から降ってくる敵を弾で撃ってスコアを稼ぎます
- 敵にぶつかるか、敵を通してしまうとゲームオーバーです

## 操作方法

- **Aボタン**: 左に移動
- **Bボタン**: 右に移動
- **A+Bボタン**: 弾を発射
- **ロゴタッチ**: ゲームをリスタート

## 遊び方

1. プレイヤーを左右に動かして敵の位置に合わせます
2. A+B で弾を発射します
3. 敵に当たるとスコアが 1 増え、新しい敵が出現します
4. 敵が最下段まで来て衝突するか、画面下まで到達するとゲームオーバーです

## ファイル

- `main.ts`: ゲーム本体のコード

## メモ

- 敵は1体ずつ出現します
- 弾は同時に1発だけ発射できます
- micro:bit 向けのシンプルな学習用ゲームとして使えます
